# ქართული აუდიო ფაილების საქაღალდე (Audio Assets)

ეს საქაღალდე გამზადებულია წინასწარ ჩაწერილი ქართული MP3 აუდიო ფაილებისთვის.
ვებრესურსი აღჭურვილია ჰიბრიდული ძრავით და მუშაობს 100% ოფლაინ:
- **თუ MP3 ფაილი ჩაწერილია**, რესურსი უპირატესობას ანიჭებს სტუდიურ ჩანაწერს.
- **თუ MP3 ფაილი არ არის**, სისტემა ავტომატურად იყენებს Web Audio API-ის ცხოველთა ხმების სინთეზატორს, ბრაუზერის `speechSynthesis`-ს (`ka-GE`) და მელოდიურ აკორდებს.
