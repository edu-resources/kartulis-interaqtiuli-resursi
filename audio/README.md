# ქართული აუდიო ფაილების საქაღალდე (Audio Assets)

ეს საქაღალდე გამზადებულია წინასწარ ჩაწერილი ქართული MP3 აუდიო ფაილებისთვის.
ვებრესურსი ავტომატურად ამოწმებს ამ ფაილების არსებობას:
- **თუ MP3 ფაილი ჩაწერილია**, რესურსი უპირატესობას ანიჭებს მას.
- **თუ MP3 ფაილი არ არის**, სისტემა ავტომატურად იყენებს ბრაუზერის `speechSynthesis`-ს (`ka-GE`) და Web Audio API-ის მელოდიურ ტონებს.
